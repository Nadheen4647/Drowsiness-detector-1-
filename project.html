Project Objective

Develop a non-intrusive safety system that actively reads facial features to prevent fatigue-related road accidents. By combining deep learning classifications with strict mathematical aspect ratios, the system accurately alerts drivers upon the first indicators of exhaustion.

Key Features

  • Geometric Ratio Analysis: Employs EAR (Eye Aspect Ratio) and MAR (Mouth Aspect Ratio) for physical dimension tracking.
  • Deep Learning Validation: Cross-checks geometric estimations with a CNN classifier to verify eye-state closures.
  • Temporal Buffer: Integrates an alert delay filter to avoid triggering on standard blinking gestures.

Eye Aspect Ratio (EAR)

EAR = (||p2 - p6|| + ||p3 - p5||) / (2 * ||p1 - p4||)

EAR computes the ratio of eye height to eye width using six coordinates surrounding the eyelids. Under normal driving conditions, the ratio is high and stable (~0.25 to 0.35). As sleepiness or micro-sleep takes over, the vertical distance drops toward zero, driving the ratio down (~<0.20).

Mouth Aspect Ratio (MAR)

MAR = (||p51 - p59|| + ||p52 - p58|| + ||p53 - p57||) / (2 * ||p49 - p55||)

MAR measures mouth open distance using vertical and horizontal outer lip points. When yawning, the vertical lips stretch apart, resulting in a distinct, high-amplitude MAR spike (often reaching >0.65 for several consecutive seconds) that can easily be differentiated from normal talking or singing.

CNN Eye-State Binary Classifier

To eliminate calibration drift from geometric parameters alone, the system feeds cropped bounding boxes of the eyes to a Convolutional Neural Network (CNN) trained on the MRL Eye Dataset (84,000+ samples).
